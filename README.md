# Compound Climb

A phone-first, view-and-record app for a compounding ladder of trade targets.
Set a starting amount, a gain per step and a number of steps; the app highlights the next target,
shows how much is still needed, and logs each win or loss with the time each target was hit.

It does not trade or connect to any exchange. All records stay in the phone's browser storage;
use **Export CSV** in the History section for a backup.

Install: open the GitHub Pages link on your phone, then *Add to Home Screen* (iPhone, Safari)
or *Install app* (Android, Chrome).
